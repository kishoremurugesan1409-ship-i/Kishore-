# Student Management System

A web-based Student Management System developed using Python Flask,
HTML, CSS, JavaScript and SQLite.

## Features

- Add student
- View students
- Update student
- Delete student
- Search students
- Student dashboard
- Database management

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Bootstrap

## Project Structure

student-management-system/

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py
